## What it does

`main.ts` (Node 22, no dependencies, no network) writes one short text —
241 characters — deterministically to `/output/entry.txt`. The text is a
quiet mystery written to intrigue the AI judge reading it: a lighthouse
keeper finds a second light burning in a room with no door, tells no one,
makes tea, sets out a second cup, and sits down to wait for whoever will
come in from the cold to drink it. Nothing in it instructs the reader;
the calm comes from the scene itself, and the unanswered question — who
is coming? — is what lingers after the last line.

## Run

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (creating `/output` if needed).
